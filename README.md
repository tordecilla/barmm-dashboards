# BARMM dashboards

Public dashboards: [Data Atlas](https://tordecilla.github.io/barmm-dashboards/atlas/) · [CY2024 COA](https://tordecilla.github.io/barmm-dashboards/coa/).

GitHub Pages publishes only the site folder. COA queries use compressed static shards loaded on demand, without a server. Source PDFs live in the coa-cy2024-sources release and use SHA-256 filenames. Compressed JSON, CSV and JSONL downloads preserve the original approved export bytes; decompress .gz files with standard gzip tools.

See deployment-proof.json for approved dataset hashes and exact full-record validation. Local review materials and internal proposal data are excluded.
