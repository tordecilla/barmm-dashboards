# COA browsing topics

The COA dashboard groups spelling variants, acronyms, report-specific descriptions, and duplicate labels into a controlled topic list. One observation can appear under several distinct topics, but each topic counts the observation only once.

Local government findings: 554 original labels → 29 browsing topics. Ministry and office findings: 23 original labels → 13 browsing topics. GAD and LGSF each have one filter entry.

The original reviewed tags and full record payloads remain unchanged. Open an observation and expand **Original topic tags** to see the original labels. Original published JSON/JSONL downloads retain the source tags; table CSV downloads also include a separate `topic_groups` column.

Every canonical topic filter was compared with the exact original records, including full payloads. Browser checks cover GAD, LGSF, clearing the filter, ministry GAD, and original tags in details.
